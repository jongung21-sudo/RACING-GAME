# NEON CIRCUIT - 2D Top-Down Arcade Racing Game 🏎️💨

웹 브라우저에서 바로 플레이할 수 있는 완성형 2D 탑다운 아케이드 레이싱 게임입니다.

---

## 🎮 게임 소개
- **스타일**: 클래식 아케이드 감성의 2D 탑다운 레이싱 게임
- **엔진**: 외부 무거운 라이브러리 없이 순수 HTML5 Canvas + Web Audio API로 구현
- **서킷**: 가속 직선로, 고속 완만 코너, 테크니컬 S-시케인, 급격한 헤어핀 구간이 포함된 오리지널 그랑프리 서킷
- **AI 경쟁**: 독자적인 속도, 제동, 추월 성향을 가진 5대의 개성 있는 AI 상대 드라이버
- **사운드**: 외부 오디오 파일 다운로드 없이 100% 실시간 절차적 합성(Procedural Synth)으로 생성되는 엔진음, 스키드음, 충돌음, 출발/완주 효과음

---

## 🕹️ 조작 방법

| 동작 | 키보드 키 |
| :--- | :--- |
| **가속 (전진)** | `W` 또는 `↑ (위쪽 화살표)` |
| **브레이크 / 후진** | `S` 또는 `↓ (아래쪽 화살표)` |
| **좌회전** | `A` 또는 `← (왼쪽 화살표)` |
| **우회전** | `D` 또는 `→ (오른쪽 화살표)` |
| **핸드브레이크 / 드리프트** | `Spacebar (스페이스바)` |
| **트랙 복귀 리셋** | `R` |
| **사운드 켜기/끄기** | `M` |

*(모바일 및 태블릿 화면 터치 컨트롤 지원)*

---

## 🏁 레이싱 팁
1. **고속 드리프트**: 급커브 진입 시 방향키와 함께 **Spacebar**를 누르면 타이어 연기와 함께 멋진 드리프트를 구사할 수 있습니다.
2. **오프로드 감속**: 아스팔트를 벗어나 **잔디**로 들어가면 속도가 약 35%로 급감합니다.
3. **방호벽 주의**: 외곽 방호벽에 충돌하면 반동으로 튕겨 나오며 속도가 크게 떨어집니다.
4. **3랩 승부**: 총 3바퀴(3 Laps)를 먼저 완주하는 차량이 1등 우승을 차지합니다.

## 📁 프로젝트 구조

```text
├── index.html          # 메인 HTML 및 UI 레이아웃
├── README.md           # 프로젝트 안내 문서
├── .gitignore          # 깃 무시 파일 목록
├── css/
│   └── style.css       # 아케이드 네온 테마 및 반응형 스타일
└── js/
    ├── audio.js        # Web Audio API 실시간 사운드 합성기
    ├── track.js        # 트랙 지오메트리, 연석, 방호벽, 체크포인트, 배경 소품
    ├── car.js          # 차량 물리, 아케이드 다이내믹스, 드리프트, 벡터 그래픽
    ├── ai.js           # 5대 AI 드라이버 주행, 코너 감속 및 추월 로직
    ├── particles.js    # 스키드마크, 연기, 흙먼지, 충돌 스파크, 스피드 라인
    ├── camera.js       # 시네마틱 부드러운 추적 카메라 및 화면 흔들림
    ├── ui.js           # 실시간 HUD, 미니맵, 카운트다운, 결과 순위표
    └── game.js         # 메인 게임 루프 및 레이스 상태 머신
```

## 🚀 실행 방법
별도의 빌드나 서버 설치 없이, `index.html` 파일을 크롬, 엣지 등 웹 브라우저에서 더블 클릭하여 바로 실행할 수 있습니다.
